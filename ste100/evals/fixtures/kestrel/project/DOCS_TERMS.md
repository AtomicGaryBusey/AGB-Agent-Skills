# Technical nouns and technical verbs

This list contains the technical nouns and the technical verbs for the Kestrel HB-200 manual. Use only these names for these items. Do not use the words in the "Do not use" column.

## Technical nouns

| Technical noun | Definition | Do not use |
|---|---|---|
| accumulator | The component that keeps hydraulic fluid at pressure after the pump stops | - |
| backup ring | The ring that prevents damage to the O-ring at high pressure | - |
| controller | The laptop computer and its benchctl software | - |
| drain plug | The plug at the bottom of the reservoir | - |
| emergency stop button | The button on the control panel that stops the pump immediately | - |
| fault code | The number and the name that the controller shows for a problem | error number |
| filter bowl | The container of the filter that you can remove | - |
| filter element | The part in the filter bowl that makes the fluid clean | cartridge |
| filter housing | The part of the filter that holds the filter bowl | - |
| manifold | The block that holds the valves and the outlet pressure sensor | - |
| MAWP | Maximum allowable working pressure. The highest pressure that is permitted in the test bench | - |
| outlet pressure sensor | The sensor that measures the pressure at the pump outlet | - |
| pressure control knob | The knob on the control panel that sets the pump pressure | - |
| pressure hose | The hose from the test port to the unit under test | - |
| pressure gauge | The gauge on the control panel that shows the pressure at the test port | - |
| relief valve | The valve that opens when the pressure is too high | - |
| reservoir | The container that holds the hydraulic fluid for the test bench | tank |
| return hose | The hose from the unit under test to the return port | - |
| return port | The port where the fluid goes back into the reservoir | - |
| sight glass | The window on the reservoir that shows the fluid level | - |
| shutoff valve | The valve that stops the flow to the test port | isolation valve |
| strap wrench | The tool that turns the filter bowl | - |
| test port | The port where you connect the unit under test | - |
| unit under test | The unit that the test bench supplies with hydraulic fluid | - |

## Technical verbs

| Technical verb | Definition |
|---|---|
| export | To write data from the controller to a file (a computer function) |
