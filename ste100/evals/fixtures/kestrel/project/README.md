# Kestrel HB-200 Hydraulic Test Bench

This manual contains the procedures and the data for the Kestrel HB-200. The HB-200 is a hydraulic test bench. Tarnhollow Fluid Systems makes it.

## Parts of this manual

- [Overview](docs/overview.md): The function and the primary parts of the test bench
- [Installation](docs/install.md): The procedure to install the test bench
- [Maintenance](docs/maintenance.md): The procedures to replace the parts and the hydraulic fluid
- [Troubleshooting](docs/troubleshooting.md): The problems, their causes, and the correction for each problem
- [Technical nouns and verbs](DOCS_TERMS.md): The approved names for the items in this manual

## Before you start

Read all the safety instructions in a procedure before you start the work. Don't operate the test bench if you are not approved to operate it.

In this manual, "controller" is the name for the HB-200 laptop computer and its software. The name of the software is `benchctl`.
