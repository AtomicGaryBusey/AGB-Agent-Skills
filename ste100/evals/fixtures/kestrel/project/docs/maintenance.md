# Maintenance

## Safety instructions

WARNING: THE ACCUMULATOR CAN HOLD PRESSURE AFTER YOU STOP THE PUMP. THIS PRESSURE CAN CAUSE INJURY. RELEASE THE PRESSURE FROM THE ACCUMULATOR BEFORE YOU DISCONNECT A HOSE.

CAUTION: USE ONLY THE APPROVED HYDRAULIC FLUID. OTHER FLUIDS CAN CAUSE DAMAGE TO THE SEALS.

You should wear safety goggles and gloves during these procedures.

## Replace the filter element

1. Push the emergency stop button.
2. Ensure that the pressure gauge shows 0 MPa.
3. Put a container, e.g. a drain pan, below the filter housing.
4. The filter bowl is then removed with a strap wrench.
5. Discard the used filter element, the used O-ring, and the used backup ring.
6. Install a new filter element in the filter bowl; the arrow on the filter element must point up.
7. Install new seals on the filter bowl.
8. Install the filter bowl on the filter housing.
9. Torque the filter bowl to 30 N·m.
10. Test the filter housing for leaks at 10 MPa.

## Replace the outlet pressure sensor

1. Push the emergency stop button.
2. Disconnect the pump outlet pressure sensor cable connector.
3. Remove the outlet pressure sensor from the manifold.
4. Install a new outlet pressure sensor in the manifold.
5. Torque the outlet pressure sensor to 25 N·m.
6. Connect the cable to the outlet pressure sensor.

## Replace the hydraulic fluid

1. Push the emergency stop button.
2. Put a container with a capacity of 50 liters below the drain plug.
3. Remove the drain plug from the bottom of the tank.
4. Let the fluid drain into the container.
5. Install the drain plug.
6. Fill the reservoir with new hydraulic fluid. Refer to the installation procedure, step 5.
