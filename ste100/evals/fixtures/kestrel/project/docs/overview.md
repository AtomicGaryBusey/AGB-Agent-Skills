# Overview

## Function

The Kestrel HB-200 is a hydraulic test bench. It supplies hydraulic fluid at a controlled pressure to a unit under test. The HB-200 can operate in the manual/automatic mode.

The relief valve opens at 110% of the MAWP. This valve prevents damage to the test bench and to the unit under test.

## Primary parts

The HB-200 has these primary parts:

- The reservoir
- The pump and the electric motor
- The filter element
- The relief valve
- The accumulator
- The control panel and the controller.

The pump moves the fluid from the reservoir through the filter element to the test port, and the pressure gauge shows the pressure.

## Pressure data

The maximum allowable working pressure (MAWP) of the HB-200 is 21 MPa. The relief valve opens at 23 MPa.

## Controller

The controller is a laptop computer with the benchctl software. It connects to the control panel through a data cable. The controller shows the pressure, the flow, and the fluid temperature. It records these values each second. You can export the recorded values to a file. The controller also shows the fault codes. Each fault code has a number and a short name.
